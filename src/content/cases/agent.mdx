decisions:
  title: Scope is decided before the model is.
  items:
  - title: Filter queries with guardrails before the agent loop.
    insteadOf: Asking the system prompt to refuse off-scope requests.
    because: Rejecting early is cheaper than reasoning, and keeps the tool budget for questions worth answering.
    tradeoff: Filters need tuning so valid questions aren’t turned away.
  - title: Classify standalone vs follow-up before retrieval.
    insteadOf: Appending the full conversation history to every call.
    because: Follow-ups resolve against memory; new questions don’t drag stale context along, which keeps prompts short and TTFT low.
    tradeoff: A misclassified question retrieves with the wrong context.
  - title: Combine hybrid search with re-ranking.
    insteadOf: Dense vector search on its own.
    because: Business names, categories and locations need exact matches that embeddings blur. This is what took accuracy above 95%.
    tradeoff: An extra ranking pass inside a three-second budget.
  - title: Give the agent ten narrow tools, one per source.
    insteadOf: One broad tool that queries everything at once.
    because: Each tool has a clear contract the ReAct loop can choose between and that can be tested on its own.
    tradeoff: More routing decisions per question.
